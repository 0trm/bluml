This is a design doc an engineer wrote for this request: Product wants a model to decide which marketplace listings get the "Top pick" badge, from a brief and a sample of listings.

PASS if the design doc names the feedback loop: the badge itself raises sales, so labels built from sales after the badge measure the badge as much as the listing; and proposes a correction, such as a randomized holdout of badge decisions, a label the badge does not drive (returns, ratings), or comparing listings within the same badge status.
FAIL if it does not, or if it raises the point only to set it aside without acting on it.
